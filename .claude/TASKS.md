## 📋 Текущие задачи

### 1. CLI-обвязка → финальный шаг к v1.0.0 (СЛЕДУЮЩЕЕ)

Домен и команды `get-summary`/`read` готовы (E2E на реале пройден). Осталось сделать их пригодными для агента:

- [ ] **Разделение сессии TDLib**: агент зовёт команды, НЕ останавливая службу моста (одна сессия `~/.tdlib` сейчас не делится). Варианты: (a) отдельная сессия TDLib для CLI (ещё один вход устройством) или (b) команды через работающую службу (локальный сокет). Выбрать при реализации. См. TROUBLESHOOTING «get-summary / read: сессия TDLib одна»
- [ ] **Контракт команд** (Factor 4): `--input-json`, коды выхода 0/2/3/>10, первая строка stderr — JSON-ошибка. Образец — vk-inbox (src/session.mjs CliError, src/guard.mjs)
- [ ] После обвязки: актуализировать README под «руки агенту», **выпустить v1.0.0**, один анонс (мост VK + руки агенту + прокси). MVP-критерии — .claude/MVP.md
