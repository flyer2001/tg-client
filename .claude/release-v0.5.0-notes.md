## 🎉 v0.5.0 - VK Bridge (Long Poll)

Управление Telegram через личное VK-сообщество — когда сам Telegram недоступен (блокировки мобильного интернета), а VK работает. Пишешь команду своему сообществу → клиент выполняет её в Telegram → ответ приходит в тот же диалог VK.

### ✨ Новые возможности

- **VK Bridge через VK Bots Long Poll**: не нужны домен, HTTPS, nginx и открытый порт — запускается хоть на домашнем ноутбуке за роутером
  - `/digest` — меню непрочитанных: каналы, группы, ЛС (архив не попадает)
  - `/get N`, `/get all`, `/get channels|groups|dm` — текст непрочитанных (с подписями к медиа)
  - `/last N [count]` — последние сообщения чата
  - `/reply N текст`, `/to username текст` — ответить / написать от своего имени
  - `/read N` — пометить чат прочитанным
  - Доступ только владельцам (`VK_BOT_OWNER_IDS`), остальные сообщения игнорируются
- **Прокси для TDLib** (`TDLIB_PROXY=socks5://…` или `http://…`): для работы там, где дата-центры Telegram недоступны напрямую
- **`tg-client dump @username`** — полная выгрузка истории чата в JSONL; **`tg-client send`** — отправка документа чанками

### 🔧 Улучшения

- **Надёжность моста**: автоматическое переподключение к VK (ошибки Long Poll `failed:1/2/3`, повтор с растущей паузой при обрыве сети), мягкая остановка по SIGINT/SIGTERM — работает под systemd
- **Меньше зависимостей**: удалены Hummingbird и webhook-сервер, осталась только `swift-log`; чистая сборка 46 → 17 секунд
- **Swift 6.4**, 0 предупреждений компилятора (включая новую диагностику retain-циклов)
- **Release-сборка со статическим Swift** (`scripts/build-release-linux.sh`): бинарь запускается на машине без Swift — нужна только `libtdjson`

### 🧪 Тестирование

- 256 unit + 65 component + 5 E2E тестов
- E2E VK Bridge проверен на реальном VK-сообществе
- Проверены паттерны тестирования конкурентности: детерминированный тест гонки без `sleep` («шпион и затвор»)

### ⚙️ Миграция со spike (`feature/vk-bot-bridge`)

- Вместо Callback API (webhook) — Long Poll: в сообществе включите **Работа с API → Long Poll API** (5.199, «Входящие сообщения»)
- Ключ сообщества нужен с правами **«Управление сообществом» + «Сообщения сообщества»**
- Переменные `VK_CALLBACK_SECRET`, `VK_CONFIRMATION_TOKEN`, `BOT_BRIDGE_HOST`, `BOT_BRIDGE_PORT` больше не нужны
- Убран личный ярлык `/to_alena` — используйте `/to username текст`
