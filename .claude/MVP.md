## Видение (пересмотрено 2026-10-15)

Личный клиент-мост между мессенджерами и **агентом**. Агент — «мозг»: читает непрочитанное, делает сводку,
по команде владельца помечает прочитанным и отвечает. tg-client даёт агенту **руки**: официальные операции
с Telegram (TDLib) и приём команд из VK-сообщества (Bots API). Сам саммари не сочиняет — отдаёт данные, сводку
формирует агент.

Что сменилось против старого MVP: доставку саммари через бота и OpenAI-текст убрали (это делает агент);
расписание/алерты заменяет агент; добавились VK Bridge и прокси для работы из РФ.

## Scope v1.0.0

**Входит (всё официальное API):**
- ✅ **VK Bridge** (v0.5.0): управление Telegram из VK-сообщества через Bots Long Poll — `/digest`, `/get`, `/last`, `/reply`, `/to`, `/read`, `/test`. Без домена/nginx.
- ✅ **Прокси для TDLib** (`TDLIB_PROXY` socks5/http): работа там, где Telegram режут.
- ✅ **Руки агенту по Telegram** (домен + команды): `get-summary` (непрочитанное → JSON + курсор, состояние не меняет), `read` (пометить прочитанным по курсору).
- ⏳ **CLI-обвязка** — финальный шаг к 1.0: контракт команд (`--input-json`, коды выхода 0/2/3/>10, JSON в stderr) и **разделение сессии TDLib**, чтобы агент звал команды не останавливая службу моста. Без этого «агент пользуется каждый день» не выполняется.

**Не входит (после 1.0):**
- Отправка от имени агентом (`send`) + whitelist адресатов.
- Обогащение сообщений (`from_name` внутри группы, `date`, медиа, `reply_to`) — для дневника/рефлексии.
- AI-текст сводки (агент делает сам; старый `OpenAISummaryGenerator` остаётся опцией).
- Mattermost как третий канал.
- VK личные сообщения — отдельный приватный инструмент `vk-inbox` (серая зона, не в этом репозитории).

## Архитектура (кратко)

```
VK-сообщество ──Long Poll──► tg-client service (TDLib, прокси) ──► Telegram
Агент ──CLI (get-summary/read/…)──► tg-client ──► Telegram
```

5 модулей: `TDLibAdapter`, `TgClientModels`, `DigestCore` (сбор, снапшот, курсор, mark-as-read),
`BotBridge` (VK Long Poll + команды), `App` (CLI-режимы). Детали — [ARCHITECTURE.md](ARCHITECTURE.md).
